# UI_SPEC v3.0

## 首页

- 同屏显示12套阵型和紧凑球场预览。
- 预览位置必须按足球语义排列：LW在左、ST在中、RW在右，左右后卫同理。

## 选秀与排阵

- 桌面端左侧固定显示阵型和已选球员，右侧显示本轮随机池券和最多5名候选；手机端纵向排列。
- 桌面端10名候选优先用两列紧凑显示，候选区内部滚动，避免整页过长。
- 每张卡默认直接显示姓名、位置、惯用脚、价格、FM式八维雷达和8项数值，无需展开才可查看。
- 雷达每个方向必须同时显示属性名称和数值。外场顺序为防守、身体、速度、视野、进攻、技术、制空、精神；门将顺序为拦截射门、身体、速度、精神、指挥防守、意外性、制空、大脚开球。
- 候选可直接拖到合法首发槽；已选球员可在首发槽之间移动，也可拖回待分配区。
- 所有拖放操作必须提供“点击球员→点击槽位”的触控替代方式。
- 选满11人后停止继续出人；11个合法槽位排满才能开始赛季。

## 赛季

- 战术在开赛前设置一次并锁定。
- 逐场显示对手、主客场、比分、进球和助攻人员；可暂停、单步、自动播放或直接跳到最终结果。
- 结果页展示积分榜、38场比赛、球队成绩和球员数据，不显示替补、换人、牌或伤病字段。
- 刷新恢复当前局；重新开始必须确认，完成后不保存阵容。
