# CODEX_TASK v3.0

当前网页原型的权威规则：

- 首页选阵型，服务器随机替代一支2025/26英超球队。
- 选秀只有11轮、11名首发；无预算、身价、替补、牌和伤病。
- 900人运行时白名单分为传奇156、球星344、球员400，配置位于 `config/draft-pools.json`。
- 每轮服务器按4/11、4/11、3/11独立生成池券，揭晓后从对应池返回最多5人。
- 候选必须兼容至少一个空缺槽位；选人和落位由同一个服务端请求原子完成。
- 浏览器只能看到公开八维和已揭晓池券；底层FM项目数值只在服务端比赛计算中使用。
- 赛季一场一场展示，自动播放可暂停，也可跳过；最终展示积分榜与球员统计。
- 当前单人局的池券序列保存在服务端；未来PVP复用同一序列给双方，候选分别随机。

修改球员位置使用 `data/manual/player-position-maintenance.csv` 和 `scripts/player-position-maintenance.mjs`。重新筛选900人使用 `scripts/build-draft-pools.mjs`。
