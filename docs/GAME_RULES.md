# GAME_RULES v3.0

## 核心流程

1. 首页只选择阵型，不选择预算。
2. 每轮随机揭晓传奇池、球星池或球员池池券，再从最多5名候选中选1人并直接放入合法首发位置；本轮不能换候选。
3. 选秀过程中直接把候选或已签球员拖入阵型；也可点击球员后点击合法位置。
4. 只选11人，不能选择第12人。11个首发槽全部合法填满后即可锁定阵容和赛季战术。
5. 玩家随机替代2025/26英超的一队，逐场模拟38轮并可跳过到赛季结果。
6. 展示每场比分与进球人员、积分榜、最终成绩和队内球员数据；重新游戏必须重新选秀。

## 选秀与位置

- 每轮候选生成后不能换一批，必须先选其中1人。
- 不提供指定位置机会，也不设固定门将轮；服务器按剩余空位保证11轮后阵容可成立。
- 系统只生成至少能填补一个当前空位的候选，避免未满11人时位置卡死。
- 最佳/第二/其他FM登记位置分别为100%/95%/90%，未登记位置不能使用。
- 候选卡直接展示FM式八维雷达、8项数值、价格、位置和惯用脚；FM单项属性只在服务端参与计算。

## 阵容与比赛

- 阵容固定为11人且全部为首发，没有替补席和自动换人。
- 当前没有红牌、黄牌、伤病、停赛和跨场体能。
- 赛季战术开始前设置一次，38轮内锁定。
- 同国家首发+1%、同联赛首发+1%，单人最多+2%；每场状态独立抽取。
- AI球队使用2025/26英超真实名单显示具体进球/助攻人员。

## 赛季数据

- 20队主客场双循环共380场，玩家参加38场。
- 球员统计包含出场、首发、分钟、进球、助攻和平均评分；门将额外统计失球、零封和扑救。
- 不展示38-0目标，不保存已完成阵容；未完成的一局刷新后可以恢复。
